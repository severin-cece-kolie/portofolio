## Instructions

1. **Images** : Placez les images des certificats dans ce dossier avec les noms exacts listés ci-dessus
2. **PDFs** : Placez les documents PDF téléchargeables dans ce dossier avec les noms exacts listés ci-dessus
3. **Format** : Les images doivent être en format JPG ou PNG, les PDFs en format PDF standard
4. **Qualité** : Assurez-vous que les images sont de bonne qualité et lisibles

## Fonctionnalités

- **Visualisation** : Cliquez sur "Voir le certificat" pour afficher l'image en grand dans une modal
- **Téléchargement** : Cliquez sur "Télécharger" pour télécharger le PDF du certificat
- **Responsive** : La modal s'adapte automatiquement aux différentes tailles d'écran
- **Accessibilité** : Fermeture avec la touche Échap ou en cliquant à l'extérieur de la modal

## Notes techniques

- Les chemins des fichiers sont définis dans `script.js`
- Les styles de la modal sont dans `styles.css`
- La modal est entièrement responsive et s'adapte aux mobiles
